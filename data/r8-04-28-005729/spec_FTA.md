# 部品正常仕様書

対象部品：コネクタ端子（発電機側ハーネス-メインワイヤーハーネス接続）

## 1. 対象部品の特定

コネクタ端子は、トライアンフボンネビルT100等の二輪車において発電機側ハーネスとメインワイヤーハーネスを接続するコネクタの雄・雌端子であり、銅合金等の金属母材に錫・銀等のメッキを施した電気接続部品である。エンジンルームまたはフレーム付近に設置され、走行振動にさらされる環境に置かれる。
<!-- [出典] 国交省リコール届出一覧表 令和8年4月28日 -->

## 2. システム内での役割

コネクタ端子は、発電機が発電した電力をメインワイヤーハーネスへ伝送する電気接続部として、低接触抵抗を維持して大電流（数十A）を安定して通電する機能を担う。表面メッキは母材の酸化・腐食を防止して接触抵抗の増大を抑制し、長期にわたる安定した導通を確保する役割を担う。

## 3. 構成・関連部品

- コネクタ端子本体（母材）：電流を通電する銅合金等の金属製端子
- 表面メッキ（錫・銀等）：母材の酸化防止と接触抵抗低減のために施される表面処理
- コネクタハウジング：端子を保持しコネクタ結合を維持する樹脂製ハウジング
- 発電機側ハーネス / メインワイヤーハーネス：コネクタ端子の両側に接続される電線束
<!-- [AI推論] 構成部品はJIS C 5402（コネクタ）およびJIS E 0501（電気接続部品）の一般知識に基づく。 -->

## 4. 作用環境入力

- 走行振動：二輪車走行中の路面・エンジン振動によるコネクタ端子の微小相対摺動（フレッティング）
- 通電発熱：大電流通電による端子部の温度上昇（電気抵抗発熱）
- 温度変化：−30℃〜+80℃の走行・屋外環境による熱サイクル（金属の膨張収縮）
- 大気中の酸素・水分：端子表面への酸化・腐食促進環境
<!-- [AI推論] 環境条件はJIS C 5402（コネクタ耐環境試験）およびISO 16750-3/-5に基づく推論。 -->

## 5. 機能・性能要件

- 接触抵抗：設計寿命にわたって接触抵抗が規定値以内（一般にJIS C 5402でミリΩ以下）を維持すること
- 表面メッキ耐摩耗性：走行振動による微小摺動（フレッティング）に対してメッキが摩耗せず母材が露出しないこと
- 耐酸化・耐腐食性：使用期間中に端子表面が酸化・腐食して接触抵抗が増大しないこと
- 通電性：発電機定格電流を安定して通電できること（過熱・溶損なし）
<!-- [AI推論] 性能要件はJIS C 5402（コネクタ試験方法）およびJIS C 3001（電線・ケーブル）に基づく推論。 -->

## 6. 正常保持状態

コネクタ端子は、表面メッキが走行振動による微小摺動（フレッティング）環境下においても摩耗せず母材を保護し、接触面の酸化・腐食が生じないことで低接触抵抗を維持し、大電流通電時の過剰発熱・溶損が生じない状態を正常とする。
<!-- [AI推論] 正常保持状態の定義はJIS C 5402およびISO 16750-5（接触振動試験）に基づく推論。 -->

## 7. 使用環境・要求条件

- 動作温度：−30℃〜+80℃（エンジン周辺走行環境）
- 耐振動性：二輪車走行振動（ISO 16750-3準拠）によるフレッティング耐久性
- 電流容量：発電機定格電流（数十A）を設計寿命にわたって安定通電できること
- 法規要件：道路運送車両の保安基準第44条（電気装置）の電気配線要件に適合すること
