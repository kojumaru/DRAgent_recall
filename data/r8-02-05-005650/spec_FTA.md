# 部品正常仕様書

対象部品：ハーネスコネクタ（ステアリングギヤボックス用）

## 1. 対象部品の特定

ステアリングギヤボックスに取り付けられたハーネスコネクタは、スバル レヴォーグ/WRX等の電動パワーステアリング（EPS）システムにおいて、ステアリングギヤボックス内の電動モータ・トルクセンサ等と車体ハーネス（EPS-ECUからの電力・制御信号線）を接続するマルチピン嵌合コネクタであり、ステアリングギヤボックス下部または側部に設置される。ロック爪機構により嵌合状態を保持する防水マルチピンコネクタである。

## 2. システム内での役割

ハーネスコネクタは、EPS-ECUからステアリングギヤボックス内の電動モータおよびトルクセンサへの電力・信号線を嵌合接続し、運転者の操舵トルク検出信号の入力とアシストモータへの電力供給を継続的に維持することで、電動パワーステアリングによる操舵力アシストを正常に機能させる機械的接続部品である。嵌合が完全な状態でロック爪がレセプタクル側の係合部に固定されることで、走行振動に対してもコネクタの抜けが防止される。
<!-- [出典] raw.json consequences: 走行振動等によりコネクタがはずれると警告灯が点灯する、ステアリングの操作力が増大する -->

## 3. 構成・関連部品

- 車体ハーネス（プラグ側コネクタ）：EPS-ECUからステアリングギヤボックスへ電力・信号を伝送するハーネスの端末コネクタ（相手側）
- EPS-ECU（電動パワーステアリング制御ユニット）：トルクセンサ信号を受信しアシストモータへの電流指令を演算する制御基板
- 電動アシストモータ：EPS-ECUの指令を受けてステアリングラックにアシストトルクを加えるモータ
- トルクセンサ：運転者の操舵トルクを検出してEPS-ECUへ信号を送るセンサ（ステアリングギヤボックス内蔵）

## 4. 作用荷重条件

- 振動荷重：走行中の路面入力・エンジン振動・操舵時の動的荷重がステアリングギヤボックスを介してコネクタ嵌合部に伝達する。エンジンルーム前部のステアリング系に取り付けられるため、ISO 16750-3 カテゴリBに相当する振動環境（周波数範囲5〜2000 Hz）に継続的にさらされる。
- 引抜荷重：走行中の振動・ハーネスの引っ張りによりコネクタ嵌合部に軸方向の抜去力が繰り返し作用する。
- 熱荷重：動作温度範囲（-40℃〜+105℃）の温度サイクルによる熱膨張差がコネクタハウジングと端子に作用する。
- 環境荷重：雨水・洗車水・泥水等がコネクタ外部に接触する環境下で使用される。

## 5. 強度・変形要件

- 嵌合保持力：コネクタが完全嵌合状態でロック爪が係合した場合、規定の抜去力（50 N以上）に対して抜去しないこと。走行中の振動・衝撃荷重に対してもロック爪の係合が維持されること。
- 接触信頼性：各ピンの接触抵抗が初期値1 mΩ以下、耐久後10 mΩ以下を維持し、電力・信号の伝達が途切れないこと（JASO D 622）。
- 嵌合完了判定：ロック爪が完全に係合した状態（クリック感確認）でのみ規定の保持力が発現し、半嵌合状態では規定保持力を下回ること。
- 防水性能：完全嵌合状態において防水等級IP67以上（JIS C 0920）を満足し、雨水・洗車水の侵入による短絡が生じないこと。

## 6. 正常保持状態

ハーネスコネクタは、車体ハーネスのプラグコネクタとステアリングギヤボックスのレセプタクルコネクタが規定の嵌合方向に完全挿入され、ロック爪が係合した完全嵌合状態を走行中も継続して維持する。走行振動・引抜荷重が繰り返し作用しても、ロック爪の係合が外れることなく嵌合状態が保持される。各ピンの電気的接触が維持されることにより、EPS-ECUからアシストモータへの電力供給とトルクセンサ信号の伝達が途切れなく継続し、電動パワーステアリングの正常なアシスト機能が保たれる。

## 7. 使用環境・要求条件

- 動作温度：-40℃〜+105℃（ISO 16750-4）
- 防水等級：IP67以上（JIS C 0920 / IEC 60529）
- 振動耐性：ISO 16750-3 カテゴリB（車体取付、ランダム振動0.5〜2000 Hz）に合格すること
- 嵌合保持力：コネクタ嵌合後、規定の抜去力（50 N以上）に対して抜去しないこと
- 接触抵抗：初期値1 mΩ以下、耐久後10 mΩ以下（JASO D 622）
- 法規要件：道路運送車両の保安基準（e-Gov）第26条（操舵装置）に基づき、電動パワーステアリングが正常な操舵アシストを提供すること
