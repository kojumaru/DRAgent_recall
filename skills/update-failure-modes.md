# /update-failure-modes — 故障モードラベル生成

## 概要

FTA評価の正解ラベルとして使う `failure_modes` を、リコール届出の raw.json から生成する。
書き方の形式は **`{部品名}が{事象}`** に統一する。

出力: `data/{recall_id}/label.json` の `failure_modes` フィールドを更新

---

## 故障モードの書き方ルール

**リコール情報の表現を変えすぎないこと。** 届出書に記載の事象をなるべくそのまま使う。

| 部品の不具合の性質 | 使う形式 | 例 |
|---|---|---|
| 物理的破損・変形・脱落が明確な場合 | `{部品名}が{物理的事象}する` | `アッパーアームシャフトが折損する` |
| 機能・性能の劣化・喪失が明確な場合 | `{部品名}が{機能名}を喪失する` | `防水パッキンが水密機能を喪失する` |

**物理的事象の例:** 折損する、破損する、損傷する、脱落する、剥離する、変形する、緩む、固着する、腐食する

**禁止:**
- raw.json（届出書）に記載のない事象を推測で追加しない
- 根本原因（「回路設計が不十分」等）の混入
- トップ事象（「意図せずドアが開く」等の最終結果）の混入

---

## Step 0 — 入力解決

`$ARGUMENTS` に recall_id が渡された場合はそれを使う。
渡されなかった場合は `data/` 配下のディレクトリを列挙してユーザーに選ばせる。

以下のファイルを Read する:
- `data/{recall_id}/raw.json` — メタ情報・不具合内容・部品リストを参照
- `data/{recall_id}/label.json` — 既存があれば現在の failure_modes を確認

---

## Step 1 — リコール内容の整理

raw.json から以下を表示する:

```
【リコール概要】
届出番号  : {recall_id}
届出者    : {notifier}
不具合部位: {defect_location}
不具合内容: {defect_description}
部品リスト: {parts[].part_name}
トップ事象: {consequences[-1]}（最悪ケース）
```

---

## Step 2 — 故障モード候補の生成

不具合内容・部品リストから、以下の観点で故障モード候補を列挙する:

1. **届出書に記載された物理現象・機能劣化を部品ごとに分解する**
   - 破損・折損・損傷 → `{部品名}が{物理的事象}する`
   - 水密・絶縁・信号等の機能低下 → `{部品名}が{機能名}を喪失する`

2. **因果の連鎖を故障モードの粒度で分解する（1〜4件）**
   - 根本に近い故障から直接原因となる故障まで

3. **届出書に記載のない事象は含めない**（根拠のある記述のみ）

以下の形式でユーザーに提示する:

```
【故障モード候補】

1. {部品名A}が{事象A}
   根拠: {raw.jsonの対応記述}

2. {部品名B}が{事象B}
   根拠: {raw.jsonの対応記述}
```

「この内容でよいですか？ 追加・変更・削除があれば教えてください。」と確認する。

---

## Step 3 — label.json への書き込み

確認が取れたら、`data/{recall_id}/label.json` を Read して現在の内容を把握し、
`failure_modes` フィールドのみを差し替えて Write する。

他のフィールド（target_component, top_event 等）はそのまま保持する。

```json
{
  "recall_id": "...",
  "manufacturer": "...",
  "vehicle": "...",
  "target_component": [...],
  "failure_modes": [
    "{部品名A}が{事象A}",
    "{部品名B}が{事象B}",
    ...
  ],
  "top_event": [...]
}
```

保存後:
```
保存しました: data/{recall_id}/label.json
failure_modes: {件数} 件
```

## 参考: 機能名一覧（機能劣化が主な場合のみ使う）

| 部品カテゴリ | よくある機能名 |
|---|---|
| シール・パッキン・グロメット | 防水機能、水密機能、気密機能 |
| 電気配線・ハーネス | 電気的絶縁機能、導通機能、信号伝達機能 |
| スイッチ・センサ | 信号出力機能、検知機能、接点導通機能 |
| ブラケット・ボルト・締結部品 | 構造保持機能、締結機能、固定機能 |
| ホース・パイプ | 流体密封機能、圧力保持機能 |
| バルブ・逆止弁 | 流量制御機能、逆流防止機能 |
| ブレーキ部品 | 制動力発生機能、制動力保持機能 |
| ECU・制御基板 | 演算機能、制御信号出力機能 |
